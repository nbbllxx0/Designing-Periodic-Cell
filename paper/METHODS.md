# Methods reference (amm 0.2.0, tool contract amm-tools/3)

Generated by `scripts/paper/docs2.py` (run `scripts/paper/make_all.py`). Every constant below is read from the amm source text (`ast`; amm is not imported) and every calibration source is checked to exist in the file named; the values are in `results/claims_ledger.csv` (asset METHODS). Citations are `file:line` or `file:function`. What a certificate does and does not guarantee: section 9.

## 1. Units and normalization

The solvers work with E_s = 1, ρ_s = 1 and cell edge a = 1 (`amm/units.py:normalize`, `amm/units.py:c_t`). Stiffness is reported as a fraction of E_s; frequency as f* = f a / c_t with the solid shear-wave speed

    c_t = sqrt( E_s / (2 (1 + ν_s)) / ρ_s ).

A physical request (Pa…GPa, Hz…MHz, mm…m) is converted with the material's E_s, ν_s, ρ_s and the cell size. A stiffness in pressure units without a material, or a frequency in Hz without a cell size, cannot be normalized and is reported as missing (UNDERSPECIFIED / need_info), not guessed (`amm/units.py:normalize`). Built-in materials: `amm/units.py:MATERIALS` (typical datasheet values, inputs of a request, not claims).

## 2. Geometry and voxelization

Three cubic-symmetric families, each a level-set field φ with solid where φ ≤ threshold (`amm/geometry.py:field`):
- **tpms**: gyroid, Schwarz P, diamond, IWP (`tpms_field`), network (φ = f) or sheet (φ = |f|), set by a target solid fraction (the threshold is found by bisection on the anti-aliased volume, `_fine_coverage`);
- **struts**: sc, bcc, octet; distance to the strut segments minus r, optional node spheres R (`_segments`, `_nodes`, `_dist_to_segments`);
- **resonator**: cube_bars (core cube edge c, square bars width w; `_box`), sphere_ligaments (core radius c, round bars diameter w).

Parameter boxes (fractions of a): tpms {'density': (0.06, 0.6)}, struts {'r': (0.04, 0.15), 'R': (0.0, 0.32)}, cube_bars {'c': (0.3, 0.86), 'w': (0.06, 0.36)}, sphere_ligaments {'c': (0.12, 0.46), 'w': (0.06, 0.34)} (`amm/atlas.py:BOX`); validity rules in `amm/atlas.py:valid` (cube_bars w ≤ c − 0.04; sphere_ligaments w ≤ 2c − 0.02; strut node sphere absent or R ≥ r + 0.03).

**Voxelization** (`amm/geometry.py:_fine_coverage`, `voxelize`, `design_cell`): each voxel gets s³ sub-samples with n s ≥ N_FINE = 96 (amm/geometry.py:133); s = max(2, ⌈N_FINE / n⌉) (`supersample`). A sub-sample's solid fraction is 0.5 − d/δ clipped to [0, 1], with d the approximate signed distance (φ − t)/|∇φ| and δ the sub-sample width (`_soft`, `_signed_distance`; exact for planes). Voxel coverage is the sub-sample mean; voxels below C_MIN = 0.01 are void (amm/geometry.py:134). `clean` keeps the largest periodically face-connected component (by solid volume) and reports the removed fraction and percolation in x, y, z (`clean`, `periodic_labels`, `percolates`). A **grid phase** translates the design by a fraction of a voxel before voxelizing (`design_cell(phase=...)`); the cell is periodic, so differences between phases are pure discretization error.

## 3. Finite elements

Voxel hexahedra on the periodic node set (`amm/fem.py:build_mesh`, `CellMesh`). Full voxels use 8-node elements with 9 Wilson-Taylor incompatible bubble modes, statically condensed, 2×2×2 Gauss (`amm/fem.py:hex8_ke`, element "hex8i"); this passes the patch test on cubes. Partial voxels use finite-cell integration: B^T D B and N^T ρ N are integrated over the element's own solid sub-samples with the midpoint rule (`amm/fem.py:fcm_tables`). Mass matrices are consistent (`amm/fem.py:hex8_me`). The isotropic solid: `amm/fem.py:elastic_D` (Lamé form, engineering shear strains yz, xz, xy). On a factorization failure the static solve is retried with a stiffness floor α K_full on partial voxels, α = FCM_ALPHA = 1e-08 (amm/certify.py:122).

## 4. Static homogenization

Find, for each of the six unit macroscopic strains ε⁰_m, a Y-periodic fluctuation χ_m with

    ∫_Y ε(v) : C_s : ( ε⁰_m − ε(χ_m) ) dY = 0   for every Y-periodic v,

and set

    C*_mn = (1/|Y|) ∫_Y ( ε⁰_m − ε(χ_m) ) : C_s : ( ε⁰_n − ε(χ_n) ) dY ,   |Y| = 1.

Discrete form (`amm/homog.py:homogenize`): K χ_m = F_m with F_m from the element affine fields χ⁰_m = x·ε⁰_m; the three rigid translations are removed by pinning node 0 (the cell must be one connected periodic component); one FP64 sparse Cholesky factorization (PARDISO, mtype 2) for the six right-hand sides; then C*_mn = Σ_e (χ⁰_m − χ_m)_eᵀ k_e (χ⁰_n − χ_n)_e. Recorded per solve: relative residual of each load case, ‖C − Cᵀ‖/‖C‖ and the smallest eigenvalue of C*.

Engineering constants (`amm/homog.py:cubic_constants`): C11, C12, C44 as cubic averages; S = C*⁻¹; E100 = 1/S11; ν100 = −S12/S11; G = C44; bulk = (C11 + 2 C12)/3; Zener = 2 C44/(C11 − C12); cubic deviation = ‖C − C_cubic‖/‖C‖. Targets may be set on density, E100, G, bulk and ν100 only; Zener, E110, E111 and the Voigt/Reuss averages are outputs (`amm/tools.py:OUTPUT_QUANTITIES`).

## 5. Bloch eigenproblem (3D, complete gaps)

Bloch waves u(x) = ũ(x) e^{i k·x} with Y-periodic ũ satisfy, for every periodic v,

    ∫_Y ε_k(v)* : C_s : ε_k(ũ) dY = ω² ∫_Y ρ v*·ũ dY ,   ε_k(ũ) = sym( ∇ũ + i k ⊗ ũ ),

discretized as the Hermitian pencil K(k) U = ω² M(k) U. The phase e^{i k·w} is applied to element nodes that wrap across a cell face (`amm/fem.py:CellMesh._phases`, `element_values`); f* = ω / (2π c_t) (`amm/bloch.py:f_to_sigma`). k is sampled on the simple-cubic irreducible zone: path Γ-X-M-Γ-R-X (`amm/bloch.py:kpath`, `SC_PATH`) and uniform random points in 0 ≤ k_z ≤ k_y ≤ k_x ≤ π (`amm/bloch.py:ibz_interior`). Cubic point symmetry of the cell is assumed (`amm/bloch.py:to_ibz`). A complete gap between bands j and j+1 is [max_k f_j, min_k f_(j+1)] over the sampled k (`amm/bloch.py:gaps`).

**Search tier** (`amm/bloch.py:GPUBands`): dense generalized Hermitian eigenproblems batched over k on the GPU in complex64 (Cholesky of M, L⁻¹ K L⁻ᴴ, eigvalsh), with deterministic assembly (a fixed-order gather instead of atomic adds) so that sessions replay exactly; CPU fallback when no CUDA device exists (not bit-identical).

**Certificate tier: inertia counts** (`amm/bloch.py:InertiaCounter.counts`). For a shift σ = (2π c_t f)², K(k) − σ M(k) is factored in FP64 as LDLᵀ on its real 2N form (PARDISO, mtype −2). By Sylvester's law of inertia, the number of negative pivots equals twice the number of Bloch eigenvalues below σ. A claim [f_lo, f_hi] above band j holds at a k exactly when count(f_lo) = count(f_hi) = j. Checks (`amm/bloch.py:certify_gap`): at Γ exactly 3 eigenvalues below f* = 0.001 (amm/bloch.py:394; a non-percolating cell fails); equal counts at every sampled k; no perturbed pivots and even raw counts. Counts are exact statements about the discretized model at the sampled k; they say nothing about unsampled k.

**Adversarial k** (`amm/bloch.py:adversarial_ks`): on a coarse mesh (n = 10, amm/certify.py:561) the GPU search tier evaluates the path plus 200 random interior points (seed 11, nev 24), then a pattern search (26 directions, step 0.15π halved each round, 6 rounds) from the 3 best starts of each bounding band; the k found are added to the certificate's count set.

**Edge estimates** (`amm/bloch.py:InertiaCounter.edge`, `_extreme_edge`): shift-invert Lanczos (ARPACK, tol 1e-7, fixed start vector for exact replay) at the symmetry points or the previous resolution's extreme k; every other k is screened by one inertia count at the current edge ± 1e-6 (relative) and solved only if it is more extreme.

## 6. Acceptance tier: certificate blocks and guards

`amm/certify.py:certify` runs the blocks below; `amm/tools.py` exposes it as the `certify` tool (profile C only).

### 6.1 Static block (`static_block`, `static_convergence`, `static_verdict`)

- Ladder (32, 48, 64) → (48, 64, 80) → (64, 80, 96) (amm/certify.py:558); every resolution is solved at grid phases 0 and 0.125, 0.25, 0.375, 0.5 voxel (amm/certify.py:126).
- Per quantity: phase means m(n₁), m(n₂), m(n₃), h = 1/n. If m is monotone with a shrinking step, the order p is fitted through the three means (`amm/bloch.py:_order`, p ∈ [0.25, 8]) and capped at STATIC_P_MAX = 1.0 (amm/certify.py:125); with r = h₃^p / (h₂^p − h₃^p): ext = m₃ + (m₃ − m₂) r, remaining error e = |m₃ − m₂| r. Otherwise, if every change is below `flat` = 0.001 (amm/certify.py:158) or within the phase noise (|Δ| ≤ s·P, P = phase spread at n₃): ext = m₃, e = max(|m₃ − m₂|, P). Else: not converged.
- Converged when e and P are ≤ tol_static = 0.05 (amm/certify.py:559; relative, absolute for ν100). Guarded bounds: lower = min(all computed values, ext − s e), upper = max(all values, ext + s e), s = STATIC_SAFETY = 2.0 (amm/certify.py:124).
- A rung is used when every targeted quantity has converged and every target is met by the guarded bound; otherwise the next rung is tried.
- Numerical checks per solve (`_static_row`): residual ≤ 1e-10 for all six load cases; asymmetry ≤ 1e-10; min eigenvalue of C* > 1e-8; no perturbed pivots; solid removed as islands ≤ 0.01; percolation in x, y, z.
- Verdict per target: certified (guarded bound clears it, quantity converged); refuted (the opposite guarded bound misses it; for a minimum on E100, G or bulk the largest computed value suffices because these converge from above, `FROM_ABOVE`); else undetermined. Invalid geometry (empty, not percolating, > 1 % islands) refutes; a solver failure is undetermined.

### 6.2 Bloch block (`bloch_block`, `gap_convergence`, `gap_verdict`)

- Counted resolutions n = 20, 30 (amm/certify.py:558); path with 4 points per leg (amm/certify.py:560) plus 10 random interior k (amm/certify.py:560, seed 0) plus the adversarial k.
- Edge-only third resolution n = 40 (amm/certify.py:361): Lanczos at the two most extreme k of the finest counted resolution; grid phases 0.25, 0.5 at the finest counted resolution (amm/certify.py:362).
- Edge guard (`amm/bloch.py:_edge_guard`): order p fitted per edge through the three resolutions, capped at P_MAX = 2.0 (amm/bloch.py:287); slower than P_MIN = 0.25 (amm/bloch.py:288) or non-monotone beyond the phase noise fails closed. ext = f₃ + d₂₃ r, err = |d₂₃| r; the safe lower edge is the maximum of all computed edges, the phase edges and ext + s·err (upper edge: minimum, ext − s·err), s = CONVERGENCE_SAFETY = 2.0 (amm/bloch.py:286). The claim must lie inside the safe interval.
- Densities of the counted resolutions must agree within 0.01 (`bloch_block`).
- Verdict: certified if counts and edge guard pass; refuted if a guarded edge bound excludes the claim; otherwise undetermined (a count failure is an abstention: edges converge from above, so a mode inside the claim on a finite mesh does not prove the converged gap closed).

### 6.3 As-built flag (`as_built_block`)

The surface is eroded and dilated by 0.01 a (amm/certify.py:559) as a shift of the signed distance; static targets (densities excluded) are re-checked by one solve at the first resolution of the rung used, and the gap counts at n = 20 on 2 path points per leg and 4 interior k. A failure sets `robust` = false; it is a flag, not required for release.

### 6.4 Bounds used for refusal (`amm/bounds.py:check`)

- V1 (Voigt, any geometry): C* ≤ φ C_s, so E(n) ≤ φ E_s, C44 ≤ φ μ_s, bulk ≤ φ K_s with φ = density_max.
- S1 (stability, cubic design space): ν100 ∈ (−1, 1/2).
- P1 (consistency): a minimum above its maximum, E100_max ≤ 0, solid fraction outside (0, 1].
- W1: a complete gap cannot contain f = 0; f_hi > f_lo.
- Hashin-Shtrikman upper bounds (porous): advisory for cubic requests, rigorous only for isotropic ones (`hashin_shtrikman_porous`). Table T11 lists the bounds with their assumptions.

## 7. Search tier, atlas and search

- `evaluate` (`amm/evaluate.py:evaluate_batch`, defaults n_static 20, n_bloch 10, one shared sub-sample grid n_fine 60; the tools use `amm/atlas.py:SEARCH_TIER` = dict(n_static=20, n_bloch=10, npts=4, nev=24, workers=4)): static homogenization on the CPU and the band diagram on the k-path on the GPU, finite-cell partial voxels. Results are labelled search tier.
- Atlas (`amm/atlas.py:grid_specs`, n1 = 28 densities per TPMS kind and mode, n2 = 24 per 2-D axis, validity rules applied; `amm/atlas.py:run`): one search-tier row per cell, band diagram kept, at ν_s = 0.3, 0.342, 0.39.
- Error model (`results/atlas/error_model.json`, `amm/atlas.py:error_model`, `err_for`): true = search / (1 + e) with e in calibrated one-sided ranges per family and quantity; gap edges: true = search − e f_mid; thin cells (feature parameter below {"tpms": 0.15, "struts": 0.06, "resonator": 0.1}) use wider ranges; calibrated domain {"resonator": {"w": 0.06}, "tpms:sheet": {"density": 0.08}, "tpms:network": {"density": 0.08}, "struts": {"r": 0.04}}; range ends include a factor 1.25 on the largest error seen, from 73 reference cells.
- Slack (`amm/atlas.py:slacks`): per target, (q − t)/|t| for a minimum, (t − q)/|t| for a maximum; for a gap, the best over the cell's gaps of min(f_lo − e_lo, e_hi − f_hi)/f_mid; overall slack = minimum. Cases: nominal, expected (median error), pessimistic, optimistic.
- Atlas verdict (`amm/atlas.py:oracle`): FEASIBLE if some calibrated cell clears every target at the pessimistic end; NOT_FOUND_IN_FAMILIES if every cell misses at the optimistic end and so does the bilinear interpolation between grid cells (`interpolated_best`); BORDERLINE otherwise. Interpolation is an estimate, not a bound.
- `search` (`amm/search.py:search`): Bayesian optimization per arm (kind, TPMS mode) with a SingleTaskGP and qLogEI over a Sobol candidate set (n_cand 1024), batch q = 8, objective "expected" (median-corrected slack), atlas rows as free seed data choosing the 3 best arms; library default budget 48 (amm/search.py:75); the `search` tool defaults to 32 and accepts 8-96 (`amm/tools.py:Session.search`).

## 8. Export, screening and session limits

- Export (`amm/export.py:build`, `surface`): marching cubes of the level-set field (resolution 64 per cell edge for the cell, 32 per cell for the tiled block by default), welded, checked watertight (`mesh_check`); STL in mm; report.json carries the outcome, the certificate reference and the disclaimers (`REPORT_DISCLAIMERS`).
- Screening (`amm/export.py:screen`, resolution 64, tiles 3): minimum solid and void feature by morphological opening with a ball, bisection to 0.25 voxel (`min_feature`, amm/export.py:179); a phase fails when more than FEATURE_TOL = 0.01 of it is thinner than the printer limit (amm/export.py:39); tiled connectivity of the block; watertight surfaces. Screening only, not a printability claim; the estimate is conservative by about 1-2 voxels.
- Session limits (`amm/tools.py`): at most 16 designs per evaluate call (amm/tools.py:80), 400 designs and 4 certificates per session (amm/tools.py:83, amm/tools.py:84).
- Reproducibility: `import amm` sets MKL_CBWR=AUTO,STRICT and MKL_NUM_THREADS=16 (`amm/_runtime.py`); a session log replays bit-exactly on the machine and code that wrote it (`amm/tools.py:replay`).

**What these settings mean.** The certificate is acceptance under stated discretization, sampling and guard assumptions, not a continuum theorem: guard bands come from fitted convergence orders and sampled grid phases, not from a-priori error bounds; a band could enter the gap between sampled k; the gap is for the infinite periodic lattice. Factors marked 'no calibration recorded' are design choices and should be stated as such in the paper (docs/concepts.md, 'What a certificate guarantees').
