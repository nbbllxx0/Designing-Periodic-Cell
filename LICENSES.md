## Vendored code

- None. No third-party source file is copied into amm/, app/, web/src/ or scripts/ (checked: no copyright or licence headers from other projects; the staged tree contains no file identical to a file of external/).
- amm/homog.py uses the same energy formulation as the author's earlier registry code (arXiv 2609.14741, MIT, copyright nbbllxx0 = the author's GitHub account), re-implemented independently; no code was copied.
- external/registry/ (that MIT repository, cloned unmodified) is excluded from the release. scripts/experiments/registry_row_check.py reads its data file `external/registry/data/catalogue.csv` when present (no code imported or run); results/registry_row_check*.log record that check.

## Data

- amm-data/1 (atlas, error model, calibration files): generated by the author with amm (scripts/atlas/run_atlas.py, calibrate.py, extend_calibration.py); no third-party data. Release asset amm-data-1.zip, licence CC-BY-4.0 (confirmed by the author 2026-11-08).
- results/ (staged subset), bench/, examples/outputs/, paper/figures, paper/tables: generated by the author's runs; under the repository licence (BSD-3-Clause, confirmed by the author 2026-11-08). The separate results archive (F7 STL files) is CC-BY-4.0 like the data bundle. files.tsv records one licence per file, so a change for results and figures is one rule in make_release.py.
- Published reference values used for verification (e.g. Lucklum and Vellekoop 2018 band edges) appear only as cited numbers in result files, not as copied data sets.
- research/related_work.csv (T1, T10): bibliographic metadata and short evidence quotes from public READMEs and abstracts, compiled by the author.
- LLM transcripts of the E4 benchmark (results/bench/e4/jobs/*): outputs of Codex runs made by the author under subscription; recorded as experimental data.
