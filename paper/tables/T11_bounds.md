# Bounds used for refusal, with their assumptions

| ID | Bound | Refuses when | Rigorous for | Effect | Assumptions | Source |
|---|---|---|---|---|---|---|
| V1 | Voigt: C* ≤ φ C_s as quadratic forms | E100_min > φ_max E_s; G_min (C44) > φ_max μ_s; bulk_min > φ_max K_s | any geometry, any symmetry | PROVEN_INFEASIBLE | two-phase solid + void; solid isotropic (E_s, ν_s); φ = solid fraction; φ_max = density_max (1 if absent) | amm/bounds.py:76 |
| S1 | Stability: C* positive definite | ν100_min ≥ 1/2 or ν100_max ≤ −1 | cubic (or isotropic) effective symmetry | PROVEN_INFEASIBLE (scoped to the cubic design space) | cubic: C11 > \|C12\|, C11 + 2C12 > 0, C44 > 0 confine ν100 to (−1, 1/2) | amm/bounds.py:81 |
| P1 | Positivity and consistency | a minimum above its maximum (density, E100, ν100); solid fraction outside (0, 1]; E100_max ≤ 0 | any | PROVEN_INFEASIBLE | moduli of a load-bearing cell are positive | amm/bounds.py:63 |
| W1 | Complete gap cannot contain f = 0 | f_lo ≤ 0, or f_hi ≤ f_lo | any | PROVEN_INFEASIBLE | three acoustic branches start at 0 at Γ and are continuous | amm/bounds.py:91 |
| HS | Hashin–Shtrikman upper bounds (porous) | bulk_min > K_HS; G_min > μ_HS; E100_min > E_HS(φ_max) | isotropic composites | advisory for cubic requests; PROVEN only when isotropy is requested | rigorous for isotropic composites only | amm/bounds.py:100 |
| - | Missing information | request cannot be stated in solver units (e.g. Hz without a cell size) | - | UNDERSPECIFIED (ask, never guess) |  | amm/bounds.py:53 |

- Checked before any search (`check_bounds`); a violated rigorous bound gives the outcome 'proven infeasible' with the bound named. `ratio_to_bound` = target / bound is reported as a margin.
- Bounds are rigorous for the stated scope only; outside the declared cubic design space S1 does not apply.
- Statements of the bounds and references (Hill 1952; Milton 2002, ch. 13) are in the module docstring of `amm/bounds.py`.
- HS audit, 43 cubic cells at n = 24 (`results/verification/hs_audit.json`, `scripts/experiments/hs_audit.py`): largest ratios bulk_over_HS 0.948, C44_over_HSmu 0.983, shear_cubic2_over_HSmu 0.986, E100_over_HSE 0.918; no cell exceeds the isotropic HS bounds, so HS stays advisory for cubic requests.
